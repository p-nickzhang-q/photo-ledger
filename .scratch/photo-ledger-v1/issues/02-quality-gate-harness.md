# 02: 质量闸门评分与数据集

**What to build:**
质量闸门 (Quality Gate) 的评分 harness：以用户提供的真实订单截图数据集（约 30–50 张，硬字段人工标注：实付款金额、日期）为输入，批量调用 01 的桌面提取管线，一条命令产出逐字段正确率报告。

闸门标准（ADR-0001）：硬字段（实付款金额、日期）≥95% 完全正确；软字段（商家、类别）≥80% 且错误可一眼修正。**不达标也是有效交付**——失败报告同样进账，触发 ADR-0001 备胎路线（PaddleOCR 两段式）讨论，不硬上。

数据集由用户提供：真实订单截图 + 人工核对过的硬字段标注表。截图与标注均不出设备/不出本机。

**Blocked by:** 01 (桌面提取管线打通)

**Status:** ready-for-agent

- [ ] 数据集就位：真实截图 ≥30 张 + 硬字段人工标注，存放于本机不入 git（.gitignore 或独立目录）
- [ ] 一条命令对全量数据集跑提取并产出逐字段正确率报告（含每张截图的逐字段对比明细）
- [ ] 报告明确给出闸门结论：PASS（硬≥95% 且软≥80%）或 FAIL（附失败字段分布）
- [ ] 模型替换、prompt 调整、口径变更后可重跑同一 harness（S1 接缝的可重复性）
