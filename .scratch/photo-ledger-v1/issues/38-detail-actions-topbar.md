# 票 38：详情页动作上提顶栏——保存常驻、删除收进 ⋮

- Owner: agent（QoderCN）
- Created: 2026-11-04
- Status: Resolved

## Resolved

- 结论（2026-11-04）：已实现并真机验证通过（vivo V2183A）。
- 证据：
  - 详情页顶栏右侧「保存」（账绿文字）+ ⋮；页面从截图上沿直接开始，无按钮行
  - 改类别 → 点顶栏「保存」→ 回列表，列表行与类别字段同步更新；再改回原值保存，数据复原
  - ⋮ →「删除这条账目」（锈红文字 + 图标）→ 确认对话框（含「同时删除原始截图」）→ 取消正常
- 单测：`:app:testDebugUnitTest` 全绿（UI 改动，无新增单测）。

## 背景 / 动机

详情页首屏是整张支付截图，原来「保存 / 删除」两个等宽大胶囊按钮在表单末尾，每次保存都要滑到底。
中途试过把按钮钉在内容顶部，可用但视觉很重（两个大块压在收据上方），且「删除」与主操作平级，
违背设计口径「账绿只给主操作、锈红只给破坏性操作」。

## 方案

- 顶栏动作：`保存` 用 `TextButton`（账绿文字，无底色，零新增垂直空间）；`删除` 收进 ⋮ 菜单，
  锈红文字 + 锈红图标，需两步才点得到（删除还有确认对话框）。
- 状态上提：新增 `EntryEditState`（merchant/amount/date/category + `toForm()`），
  在 `AppScaffold` 层持有（按 entry.id remember），顶栏「保存」与表单共用同一份状态。
- `EntryEditScreen` 去掉内部按钮行与 `onSave`，删除对话框改为受 `requestDelete` 控制，
  删除入口只在顶栏。
