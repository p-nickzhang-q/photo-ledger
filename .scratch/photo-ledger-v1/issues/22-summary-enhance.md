# 票 22：汇总强化（环比 / 单笔画像 / 月度条形）

- Owner: agent（QoderCN）
- Created: 2026-09-21
- Status: Resolved

## 背景 / 动机

P1 第二项（2026-09-21 定序：搜索 → **汇总强化** → 支付页噪音裁剪）。
现有汇总页（票 09）只有「当月合计 + 类别占比 + 历史各月文字行」，回答不了
「这个月比上月花得多吗」「单笔平均多大」「哪个月花得最多」。

## 方案

全部轻量统计，数据口径仍是 Entry.amountPaid，纯函数 + JVM 单测：

1. **环比**：当月 vs 上月合计，±%（涨红降绿）；上月无数据不显示。
2. **当月单笔画像**：平均单笔（合计/笔数）、最高单笔（带类别标注，
   商家多为空手填所以标注回退链 商家→类别）。
3. **历史各月迷你条形**：每月行下加比例条（该月/全期最大月），扫一眼即知分布。

类别×月份趋势不做：当前数据量收益低、UI 重，有需求再立票。

## 交付

- `data/SummaryStats.kt`：monthOverMonth / monthStats 纯函数。
- `SummaryScreen`：月度汇总块加环比与单笔行；历史各月加迷你条形。
- `SummaryStatsTest`：环比正负零、上月缺失、平均/最高、空月。

## Resolved

- 结论（2026-09-21）：按方案交付。`data/SummaryStats.kt`（monthOverMonth / monthStats）+
  SummaryScreen 三处增量（环比行 / 单笔画像行 / 历史各月迷你条形）。
  5 个 JVM 单测全过；真机 0.4.7（versionCode 16）汇总页截图验证：
  环比 +1315.5%（9月 1142.28 vs 8月 80.7）、平均/最高单笔与商家标注、
  历史条形比例均与数据一致。
- 遗留观察：环比在月度差异大时百分数会很夸张（本月真机 1315.5%），先原样展示，
  视觉不适再考虑封顶或改差额为主展示。类别×月份趋势未做（见方案）。
