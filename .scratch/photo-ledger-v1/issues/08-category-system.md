# 08: 类别体系

**What to build:**
类别 (Category) 体系：内置默认八类种子（餐饮、购物、交通、居住、医疗、娱乐、通讯、其他）；类别管理页支持新增/重命名/删除；删除类别时其下 Entry 归入"其他"而不丢账；提取时把用户当前类别列表注入 prompt，使类别建议与用户自己的体系一致。

注入 prompt 后必须用 02 的 harness 重跑质量闸门，确认软字段（类别建议）不因注入自定义类别而降级——这是本票独有的回归关卡。
