# 票 42：识别引擎设置页与启动/导入门禁

- Owner: agent（QoderCN）
- Created: 2026-11-18
- Status: Resolved

## Resolved

- 结论（2026-11-18）：新增 `Page.CloudSettings` + `CloudSettingsScreen`；⋮ 菜单「识别引擎」入口；首启、相册守卫、预加载三处门禁按引擎区分。
- 证据：`:app:compileDebugKotlin` 与 `:app:testDebugUnitTest` 通过。
- 真机：首次切云端弹出告知对话框（明示上传到所填 host）；确认后引擎切换、三项配置保存、测试连接成功；重装 APK 后配置与 consent 保持；⋮ → 识别引擎入口正常。
- 未验证：配置不完整时的引导、无端侧模型启动（设备上模型已安装，未构造该组合）。

## 背景

云端识别是可选路径，必须在 UI 上可切换、可配置，并在首次开启时完成隐私告知；同时云端模式不应被端侧模型缺失拦住。

## 方案

- 设置页：引擎单选（端侧内置默认 / 云端大模型）；Base URL、模型名、API Key（默认掩码，可显示）；「测试连接」发最小文本请求。
- 首次切云端弹告知：明确「压缩截图会上传到 <host>，可能含订单号/商品/金额」，确认后才写 `consent_done`。
- `launchGalleryPick`：云端模式检查配置完整性，不要求端侧模型；配置不完整引导到设置页。
- 首启引导：`cloudReady` 时不再强制进模型管理页。
- `preloadEngines`：云端模式跳过端侧模型预加载（省内存；回退时懒加载）。

## 验收

- 未同意不能切到云端；切回端侧立即生效。
- 云端配置不完整时导入被引导到设置页，而不是进队列白等失败。
- 无端侧模型 + 云端已配置：可进入 App 并导入。
