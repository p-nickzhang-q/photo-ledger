# 07: 导入队列与分享入口

**What to build:**
导入队列 (Import Queue)：一次多选截图或从系统分享（相册/微信"分享到照片记账"）进入同一队列，逐张提取，每项状态可见（排队/提取中/成功成 Draft/失败/去重命中）；图片内容哈希去重，重复导入给出"这张已导入过"提示而不静默丢弃；提取失败保留截图并给空表单可手工成 Entry。

接缝 S2 测试在本票落地（fake 提取器注入，不碰真模型）。

**Blocked by:** 05 (端侧图像提取端到端), 06 (Draft 确认流与账目库)

**Status:** ready-for-agent

- [ ] 相册多选与系统分享（intent-filter）两条路都汇入同一队列
- [ ] 队列逐张处理，单张失败不阻塞后续；每项状态实时可见
- [ ] 内容哈希去重：重复截图提示"已导入过"，不重复成账
- [ ] 失败项保留截图 + 空表单，可手工成 Entry 或明确放弃
- [ ] S2 接缝测试（fake 提取器）：顺序处理、失败不阻塞、去重命中、状态事件序列正确
