# 数据永不上云：本地优先边界

photo-ledger 是无账号、无云端的纯本地应用：账目数据、照片、提取结果 100% 留在设备上，永不自动上云。联网仅允许两类：模型文件下载（源可切换官方 HuggingFace / hf-mirror 镜像，同时支持本地文件导入兜底）和用户手动触发的 CSV/JSON 导出。明确不做：账号体系、崩溃上报、云同步、自动备份到第三方。

这是产品定义的一部分而非实现细节——未来任何"加个 Firebase 同步"之类的建议都应先推翻本 ADR，而不是顺手加上。

## 修订（2026-09-24，票 31）

联网白名单追加第三类：**版本更新检查**——目标仅 `api.github.com/.../releases/latest`（只读、不带任何用户数据/设备标识），每次冷启动至多一次 + 手动触发，失败静默。账本/照片/提取全链路依旧零联网。更新包获取走浏览器打开 Release 页，App 本体不做应用内下载安装。
