# 可选云端视觉识别引擎（修订 ADR-0003 的零联网边界）

日期：2026-11-18。状态：已接受。关系：修订 ADR-0003「数据永不上云」的绝对边界；ADR-0004 的端侧 OCR + 小模型仍是默认路线。

## 背景

端侧 0.6B 抄写中文商户名太弱，merchant 已于 2026-09 退出模型输出；账目记录也没有「具体内容」。用户希望可以选择把截图交给视觉大模型，一次拿到商家与商品名列表，同时接受端侧仍作为默认与回退路径。

## 决定

- **识别引擎二选一**：端侧内置（默认）或云端大模型（可选）。设置存于应用私有 `SharedPreferences("cloud")`。
- **云端模式**：截图压缩（长边 1568、JPEG 85）后以 data URL 发送到用户自填的 OpenAI 兼容 `/chat/completions`（仅 https），一次请求返回 `{"orders":[...]}`，含 merchant / content / amountPaid / datePaid / category；支持一图多单。
- **失败回退**：网络、HTTP、解析或配置错误时，若端侧模型齐备则自动回退端侧管线，并在导入队列项标注原因；否则该项失败并给出可读原因。配置不完整直接引导到设置页。
- **隐私门槛**：默认关闭；首次开启必须确认告知（明确会上传截图原图到该 host）；**Key 仅存本机私有目录，日志不记录 Key / 请求体 / 截图内容**。
- **端侧契约不动**：PromptBuilder / GrammarGenerator / DraftNormalizer 与 30 张质量闸门不受影响；JSON Schema / GBNF 不新增字段。Draft 新增 `content` 仅由云端写入，端侧默认空串。
- **校验兜底**：云端结果仍做金额范围（0 ≤ x < 100 万）、日期格式（yyyy-MM-dd，可空）、类别有效性（不在用户列表则落「其他」并标记待复核）硬校验。
- **兼容性注记**：OpenCode Go 网关要求 `x-opencode-session` 头；客户端仅在 `opencode.ai` 端点附加会话 ID（存 CloudPrefs，安装级稳定），避免向其它 OpenAI 兼容服务发送未知头。请求自带 `User-Agent: photo-ledger/1.0`（网关拒绝库默认 UA）。
- **速度**：快速模式（默认开启）对 DeepSeek V4 系列发送 `reasoning_effort: "none"` + `max_tokens: 2048`，跳过深度思考直接出 JSON——同一订单图实测 7.2–10.5s → 2.7–5.1s，completion 356–544 → 51 tokens，字段一致。复杂截图可关闭该开关。

## 后果与风险

- ADR-0003 的联网白名单新增一类：**云端识别**（仅用户显式开启时发生，上传目标是用户自己配置的第三方服务）。账号体系、云同步、崩溃上报、自动备份到第三方仍明确不做。
- README 与隐私说明从「绝对零上传」改为「默认零上传，可选云端」；两者必须同步修改，避免口径分裂。
- 云端模式不依赖端侧模型；无端侧模型时无法回退，失败即该项失败。
- 云端质量不归 30 张端侧闸门管；依赖严格解析与确认页人工核对。类别漂移用「其他」+ needsReview 兜底，不静默错分。
- 上传的是压缩截图原图，可能包含订单号、商户、商品、金额等信息；风险由用户选择的第三方服务承担，应用侧只保证「默认关闭 + 开启前告知 + 可随时切回」。
